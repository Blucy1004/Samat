# Samat Studio 엔진

Samat Studio는 `.hy` 장면 파일 없이 프로젝트의 오브젝트와 오브젝트별 Samat 스크립트를 편집하고 실행합니다. 프로젝트는 단일 `.samatproj` 파일로 저장합니다.

## 사용하기

1. Studio에서 **오브젝트 추가**를 눌러 스프라이트를 만듭니다.
2. 스테이지에서 드래그하거나 속성 패널에서 이름, 위치, 크기, 색상을 정합니다.
3. 코드 편집 탭에서 선택한 오브젝트의 `.st` 코드를 작성합니다.
4. **전체 실행**을 눌러 프로젝트의 오브젝트 스크립트를 함께 실행합니다.

오브젝트의 코드는 해당 오브젝트의 지속 실행 세션에서 동작합니다. `on start`는 실행을 시작할 때 한 번 호출하고, `on update`는 매 프레임 호출합니다.

## 엔진 함수

| 함수 | 동작 |
| --- | --- |
| `deltaTime()` | 이전 프레임 이후 흐른 시간(초)을 반환합니다. |
| `keyDown("a")` | 키가 눌린 동안 `true`를 반환합니다. WASD와 방향키 이름(`arrowleft` 등)을 사용할 수 있습니다. |
| `touching("오브젝트 이름")` | 이름이 일치하는 다른 오브젝트와 사각형이 겹치면 `true`를 반환합니다. |

오브젝트 위치는 스크립트의 전역 `x`, `y` 변수로 제어합니다. 스테이지 왼쪽 위가 `(0, 0)`이고, Y 좌표는 아래쪽으로 증가합니다.

```samat
let x = 120.0
let y = 100.0
let speed = 180.0

on update:
    if keyDown("a"):
        x -= speed * deltaTime()
    if keyDown("d"):
        x += speed * deltaTime()
```

키 입력 이벤트도 사용할 수 있습니다.

```samat
let moving = false

on key.a.pressed:
    moving = true

on key.a.released:
    moving = false
```

## 범위

현재 엔진의 스프라이트는 Studio에서 추가하는 색상 사각형입니다. 이벤트 실행, 프레임 시간, 키 상태, 사각형 겹침 확인을 제공합니다. 이미지 파일 가져오기, 물리 시뮬레이션, 애니메이션 타임라인은 아직 포함하지 않습니다.
