실행 가능한 Samat 예제 
import jm.math

fn sumEven(limit: Int) -> Int:
    let total = 0
    for number in 1..limit:
        if number % 2 == 0:
            total += number
    return total

let evenTotal = sumEven(10)
let root = sqrt(81.0)
print("짝수 합:", evenTotal, "제곱근:", root)
모듈 jm.math를 가져온다.

함수 sumEven(limit: Int) -> Int:
    정수 변수 total을 0으로 정한다.
    1부터 limit까지 number를 반복하며:
        number % 2 == 0 라면:
            total를 total + number로 정한다.
    total를 반환한다.

정수 변수 evenTotal을 sumEven(10)으로 정한다.
실수 변수 root를 sqrt(81.0)으로 정한다.
함수 print("짝수 합:", evenTotal, "제곱근:", root)를 실행한다.
같은 기능, 같은 AST. Code Syntax와 訓C正音은 서로 다른 표면 문법으로 같은 Samat 프로그램을 표현합니다.

직접 실행해 보기

저장소를 내려받고 Samat을 빌드한 다음 `.st` 파일을 실행하세요.

필요한 도구CMake 3.24 이상과 C++20 컴파일러가 필요합니다. Windows에서는 Visual Studio 2022, Linux에서는 GCC 또는 Clang을 사용할 수 있습니다.

완성된 예제는 저장소의 examples/Samat/v1.0에서 확인하세요.
# Windows PowerShell
cmake -S . -B build -A x64
cmake --build build --config Release
.\build\Release\Samat.exe run .\examples\Samat\v1.0\hello.st

# Linux
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/Samat run examples/Samat/v1.0/hello.st
